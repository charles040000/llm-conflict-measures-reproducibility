# Prompt files

This directory contains the prompt materials used for article labeling:

- `system_prompt.txt` is the exact finalized system prompt used for the production labels.
- `user_prompt.txt` is the exact finalized article-level prompt template.
- `prompt_development_notes.md` documents the two evaluated prompt versions and the revisions made between them.

The initial prompt was edited in place during development, so its exact full text was not retained as a separate snapshot. The development notes describe its structure, evaluation, identified problems, and the changes that produced the archived final prompt. They do not present a reconstructed file as an exact historical prompt.
